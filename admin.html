ACESSO RESTRITO

Entrar como administrador

Ainda não tenho um administrador. Como criar?
  1. Configure o banco com segurança. No Supabase, abra SQL Editor → New query e execute os arquivos da pasta sql, nesta ordem: marketplace-admin.sql, financeiro-locacoes.sql e security-hardening.sql. Se o projeto já está configurado, execute apenas security-hardening.sql.
  2. Crie o usuário. Abra Authentication → Users → Add user no Supabase e crie seu usuário com seu e-mail e uma senha. Não habilite cadastro público para visitantes.
  3. Marque esse usuário como administrador. Informe o mesmo e-mail criado no Supabase. O botão gera o comando para executar em SQL Editor → New query: 
    Preencha o e-mail acima para gerar o SQL.
    O comando verifica que encontrou exatamente 1 conta e preserva os outros metadados. Depois, entre novamente para carregar a permissão.

Importante: não coloque a chave service_role no site e não compartilhe sua senha. A criação do usuário é feita no painel do Supabase, nunca por um formulário público.
