ACESSO RESTRITO

Entrar como administrador

Ainda não tenho um administrador. Como criar?
  1. Execute a migração do projeto. No Supabase, abra SQL Editor → New query, cole o conteúdo de sql/marketplace-admin.sql e clique em Run. Ela cria os campos de disponibilidade, as configurações do WhatsApp e as regras de acesso.
  2. Crie o usuário. Abra Authentication → Users → Add user no Supabase e crie seu usuário com seu e-mail e uma senha. Não habilite cadastro público para visitantes.
  3. Marque esse usuário como administrador. No SQL Editor → New query, troque o e-mail de exemplo pelo e-mail criado acima e execute: 
    update auth.users
set raw_app_meta_data =
  coalesce(raw_app_meta_data, '{}'::jsonb) ||
  '{"role":"admin"}'::jsonb
where email = 'SEU_EMAIL_AQUI';
    Confira se o comando atualizou exatamente 1 usuário. Depois, entre aqui com o e-mail e a senha criados. Se já estava conectado, saia e entre novamente.

Importante: não coloque a chave service_role no site e não compartilhe sua senha. A criação do usuário é feita no painel do Supabase, nunca por um formulário público.
